# 🌌 距離 × ⏳ 時間  
## なぜ物理の話は、いつも噛み合わなくなるのか

物理は一つしかない。  
だが人間は、**スケールが変わるたびに別の世界を見ている**。

その境界は、理論でも専門でもない。  
**接頭語（f,p,n,μ,m,k,M,G,T）**だ。

---

| 接頭語 | 記号 | 値 |
|---|---|---|
| フェムト | f | $10^{-15}$ |
| ピコ | p | $10^{-12}$ |
| ナノ | n | $10^{-9}$ |

| ミリ | m | $10^{-3}$ |

| メガ | M | $10^{6}$ |
| ギガ | G | $10^{9}$ |
| テラ | T | $10^{12}$ |

**この一段ずつが、世界の切替スイッチだ。**

---

## 🌌 距離：Åから宇宙まで、同じ m

| 世界 | 距離 |
|---|---|
| 原子半径 | 1 Å = $10^{-10}\,\mathrm{m}$ |
| トランジスタ | 数 nm = $10^{-9}\,\mathrm{m}$ |
| 細胞 | 10 μm = $10^{-5}\,\mathrm{m}$ |
| 人間 | 1 m = $10^{0}\,\mathrm{m}$ |
| 富士山 | 4 km = $4\times10^{3}\,\mathrm{m}$ |
| 地球半径 | 6.4 Mm = $6.4\times10^{6}\,\mathrm{m}$ |
| 地球–太陽 | 1 AU = $1.5\times10^{11}\,\mathrm{m}$ |
| 太陽系 | $\sim10^{13}\,\mathrm{m}$ |
| 銀河 | $\sim10^{21}\,\mathrm{m}$ |
| 可観測宇宙 | $\sim10^{26}\,\mathrm{m}$ |

**Å → nm → μm → m → km → AU → 光年**  
すべて同じ「距離」だ。

だが、  
Åの世界で意味を持つ話は、kmの世界では消える。  
kmの常識は、銀河では無意味になる。

---

## ⏳ 時間：fsと宇宙年齢は、同じ秒

| 世界 | 時間 |
|---|---|
| 電子遷移 | 1 fs = $10^{-15}\,\mathrm{s}$ |
| 回路遅延 | 1 ns = $10^{-9}\,\mathrm{s}$ |
| 制御周期 | 1 ms = $10^{-3}\,\mathrm{s}$ |
| 人の反応 | 1 s = $10^{0}\,\mathrm{s}$ |
| 1日 | $10^{5}\,\mathrm{s}$ |
| 1年 | $3\times10^{7}\,\mathrm{s}$ |
| 江戸時代 | $\sim10^{10}\,\mathrm{s}$ |
| 縄文時代 | $\sim10^{12}\,\mathrm{s}$ |
| 地球誕生 | $\sim10^{17}\,\mathrm{s}$ |
| 宇宙年齢 | $\sim4\times10^{17}\,\mathrm{s}$ |

フェムト秒の世界から見れば、  
人類史は「完全に静止」だ。

---

## 🧠 なぜピンと来ないのか

人間が直感できるのは  
**せいぜい 10⁻³ ～ 10³ の6桁程度**。

それを超えた瞬間、  
同じ単位でも **別の物理に見えてしまう**。
