# 005.【Python基礎】 まとめて計算する

## 📊 Pythonで「まとめて計算できる」

Pythonは、  
**たくさんの数を一気に扱う**のが得意です。

ここでは、  
電流を少しずつ変えたときの  
**V–I 関係をまとめて計算**します。

---

## ✅ できること

- 複数の値を一度に扱える  
- 同じ計算をまとめて実行できる  
- 手計算や表計算から解放される  

---

## ⚡ デモ：V–I データの一括計算

```python
import numpy as np

R = 100.0  # resistance [ohm]

I = np.linspace(0, 0.05, 50)  # current [A]
V = R * I                    # voltage [V]

print(V)
```

---

## 👀 何が起きているか

- 電流 I は **配列（たくさんの値）**
- 電圧 V も **まとめて計算**
- for 文は書いていない

👉 **「まとめて計算する」感覚**が重要です。

---

## 💡 ポイント

- Pythonは「1個ずつ」ではなく「まとめて」処理する
- データが増えても、コードはほぼ同じ

---

## 📝 まとめ

- Pythonは大量の計算に強い
- 同じ計算を何度も書かなくてよい

これが分かればOKです。
