# 🌌 距離 × ⏳ 時間  
## 同じ物理なのに、オーダーが変わると世界が切り替わる

物理は一つしかない。  
だが人間は、**接頭語（f,p,n,μ,m,k,G,T）ごとに別の世界として理解している。**

---

## 🔑 まずは共通言語：SI接頭語

| 接頭語 | 記号 | 値 |
|---|---|---|
| フェムト | f | $10^{-15}$ |
| ピコ | p | $10^{-12}$ |
| ナノ | n | $10^{-9}$ |
| マイクロ | μ | $10^{-6}$ |
| ミリ | m | $10^{-3}$ |
| （基準） | – | $10^{0}$ |
| キロ | k | $10^{3}$ |
| メガ | M | $10^{6}$ |
| ギガ | G | $10^{9}$ |
| テラ | T | $10^{12}$ |

**接頭語が変わる＝見ている物理世界が変わる。**

---

## 🌌 距離：Å から 宇宙まで

| 対象 | 距離 |
|---|---|
| 原子 | 1 Å = $10^{-10}\,\mathrm{m}$ |
| トランジスタ | 数 nm = $10^{-9}\,\mathrm{m}$ |
| 細胞 | 10 μm = $10^{-5}\,\mathrm{m}$ |
| 人間 | 1 m = $10^{0}\,\mathrm{m}$ |
| 地球半径 | 6.4 Mm = $6.4\times10^{6}\,\mathrm{m}$ |
| 地球–太陽 | 1 AU = $1.5\times10^{11}\,\mathrm{m}$ |
| 太陽系 | $\sim10^{13}\,\mathrm{m}$ |
| 銀河直径 | $\sim10^{21}\,\mathrm{m}$ |
| 可観測宇宙 | $\sim10^{26}\,\mathrm{m}$ |

**Å・nm・km・光年は、同じ「距離」だが、直感は完全に別物になる。**

---

## ⏳ 時間：fs から 宇宙年齢まで

| 対象 | 時間 |
|---|---|
| 電子遷移 | 1 fs = $10^{-15}\,\mathrm{s}$ |
| クロック | 1 ns = $10^{-9}\,\mathrm{s}$ |
| 制御周期 | 1 ms = $10^{-3}\,\mathrm{s}$ |
| 人の反応 | 1 s = $10^{0}\,\mathrm{s}$ |
| 1年 | $\sim3\times10^{7}\,\mathrm{s}$ |
| 江戸時代 | $\sim10^{10}\,\mathrm{s}$ |
| 縄文時代 | $\sim10^{12}\,\mathrm{s}$ |
| 地球誕生 | $\sim10^{17}\,\mathrm{s}$ |
| 宇宙年齢 | $\sim4\times10^{17}\,\mathrm{s}$ |

フェムト秒の世界から見れば、  
人類史は「ほぼ静止」である。

---

## 🧭 まとめ

距離も時間も連続している。  
**断絶しているのは、人間のスケール感覚のほうだ。**
