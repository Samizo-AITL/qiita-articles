# 004.【Python基礎】 計算して実行結果を見る

## 🧮 Pythonで「計算できる」

Pythonを使うと、  
**数式を書いて ▶ を押すだけで計算結果が得られます。**

ここでは VS Code を使って、

- 書く ✍️  
- 実行する ▶  
- 結果を見る 👀  

という最小の流れを確認します。

---

## ✅ できること

- Pythonで数を計算できる  
- 変数に意味を持たせられる  
- 実行すると結果が表示される  

---

## ⚡ デモ：オームの法則（V–I）

```python
R = 100.0   # resistance [ohm]
I = 0.02    # current [A]

V = R * I   # voltage [V]

print("R =", R, "ohm")
print("I =", I, "A")
print("V =", V, "V")
```

## 💡 ポイント

- Pythonは **計算機として使える**
- ▶（Run）を押すとコードが動く
- 結果はそのまま表示される

👉 文法を覚える必要はありません。

---

## 📝 まとめ

- Python = **式を書いて計算する道具**
- VS Code = **書いて ▶ を押す場所**

この理解で十分です。
