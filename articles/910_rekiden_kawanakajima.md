## 🧮 判定ルール（AI用）

```
戦闘結果 ＝
主将の統率
＋ 行動補正
＋ 家臣団の平均武勇
＋ ダイス（1d20）
```

### 行動補正
- 正面攻撃：+0  
- 側面攻撃：+5（成功時、追加被害）  
- 夜襲：+8（成功時、敵士気 −15）  
- 本陣防御：+5（次ターン有利）

## ⚡ 見せ場イベント：一騎打ち（激アツ）

### 発生条件
- 両軍士気が50以上  
- プレイヤーが「一騎打ち」を選択  

### 判定
```
武勇 ＋ ダイス（1d20）
```

### 結果
- 勝利：敵全軍士気 −30 💥  
- 敗北：自軍士気 −30 😱  
- 引き分け：両軍士気 −10
