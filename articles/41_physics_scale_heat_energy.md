# 🔥 熱 × ⚙️ エネルギー  
## なぜ最後は、いつも「熱」になるのか

論理も、構造も、意図も関係ない。  
**エネルギーは保存され、逃げ場を失えば熱になる。**

これは思想ではない。  
**物理法則そのもの**だ。

---

| 接頭語 | 記号 | 値 |
|---|---|---|
| フェムト | f | $10^{-15}$ |
| ピコ | p | $10^{-12}$ |
| ナノ | n | $10^{-9}$ |
| マイクロ | μ | $10^{-6}$ |
| ミリ | m | $10^{-3}$ |
| （基準） | – | $10^{0}$ |
| キロ | k | $10^{3}$ |
| メガ | M | $10^{6}$ |
| ギガ | G | $10^{9}$ |
| テラ | T | $10^{12}$ |

**f → p → n → μ → m → k → M → G → T**  
この一段ずつで、扱っている世界が変わる。

---

## 🔥 熱：エネルギーの最終形態

エネルギーは消えない。  
形を変えるだけだ。

- 運動 → 摩擦 → 熱  
- 電気 → 抵抗 → 熱  
- 光 → 吸収 → 熱  

**逃げ道を失ったエネルギーは、必ず熱になる。**

---

## ⏳ 熱は「遅れて」効いてくる

| 世界 | 時間スケール |
|---|---|
| チップの温度上昇 | ms ～ s |
| 機器の劣化 | 年（$10^{7}$ s） |
| 建造物の疲労 | 十年 ～ 百年 |
| 地質変動 | 百万年 ～ 億年（$10^{13}$～$10^{15}$ s） |

発生は一瞬。  
破壊は遅延。  
**これが熱の怖さだ。**

---

## 🧠 なぜ人間は熱を甘く見るのか

人間の感覚は、

- 見える  
- 触れる  
- すぐ起きる  

現象に最適化されている。

熱は、

- 見えない  
- 遅れてくる  
- 累積する  

だから直感から外れる。
