# 🌌 距離 × ⏳ 時間  
## 同じ物理なのに、距離と時間で世界は完全に変わる

物理は一つしかない。  
だが、人間が理解している物理の世界は、**距離と時間のオーダー（桁）**で分断されている。

---

## 🌌 距離：m は同じ、世界は別

| 対象 | 距離 |
|---|---|
| 原子 | 0.1 nm = $10^{-10}\,\mathrm{m}$ |
| トランジスタ | 数 nm = $10^{-9}\,\mathrm{m}$ |
| 人間 | $10^{0}\,\mathrm{m}$ |
| 地球半径 | $6.4\times10^{6}\,\mathrm{m}$ |
| 地球–太陽 | $1.5\times10^{11}\,\mathrm{m}$ |
| 太陽系 | $10^{13}\,\mathrm{m}$ |
| 銀河直径 | $10^{21}\,\mathrm{m}$ |
| 可観測宇宙 | $10^{26}\,\mathrm{m}$ |

原子と銀河を、同じ「m」で書いている。  
この時点で、人間の直感はすでに破綻している。

nmの世界では界面や量子ゆらぎが支配し、  
kmを超える世界では重力と質量が支配する。

---

## ⏳ 時間：s は同じ、因果が崩れる

| 対象 | 時間 |
|---|---|
| 電子遷移 | 1 fs = $10^{-15}\,\mathrm{s}$ |
| クロック | 1 ns = $10^{-9}\,\mathrm{s}$ |
| 制御周期 | 1 ms = $10^{-3}\,\mathrm{s}$ |
| 人の反応 | $10^{0}\,\mathrm{s}$ |
| 江戸時代 | 約300年 $\approx10^{10}\,\mathrm{s}$ |
| 縄文時代 | 約1万年 $\approx10^{12}\,\mathrm{s}$ |
| 地球誕生 | 約45億年 $\approx10^{17}\,\mathrm{s}$ |
| 宇宙年齢 | 約138億年 $\approx4\times10^{17}\,\mathrm{s}$ |

フェムト秒の世界から見れば、  
人類史はほとんど「静止」に等しい。

---

## 🧭 まとめ

距離も時間も物理的には連続している。  
断絶しているのは、人間のスケール感覚のほうだ。
